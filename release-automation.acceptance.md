# Release automation acceptance

Owner: lead. Operational obligations and [ADR-0003](docs/ADR/ADR-0003-versioned-publishing.md) define this cross-cutting change.

- OP-REL-001 / AC-REL-001: README exposes linked CI, release, NuGet version/download, license and supported runtime badges from real providers. VSIX packaging accepts the badges.
- OP-REL-002 / AC-REL-002: one stable version bump updates extension, root lock metadata and .NET tool consistently. Reject malformed/downgraded versions and existing drift before writes; a check mode is read-only. Tests use real temporary files.
- OP-REL-003 / AC-REL-003: only a successful main three-OS CI may automatically create a new immutable matching version tag and explicitly dispatch Release. PRs never write tags or publish. Existing historical tags are preserved; unchanged versions do not create another release.
- OP-REL-004 / AC-REL-004: Release builds and tests version-matched VSIX/NuGet artifacts, smoke-installs the packaged tool before upload, and exposes manual dispatch for recovery. GitHub publishes tested assets independently of NuGet upload. NuGet publication succeeds when `dotnet nuget push` accepts the package or reports an existing duplicate; no public-install or indexing poll follows. The user explicitly approved version 0.1.2; preserve its immutable tag.
- OP-REL-005 / AC-REL-005: Marketplace accepts a public stable release tag, validates VSIX identity/display name/version, and publishes that exact asset. The branded identity is managedcode.managedcode-nuget-package-manager / NuGet Package Manager by ManagedCode. OIDC or PAT comes only from configured credentials. Missing authentication must produce a clear error. Automatic publishing uses MARKETPLACE_PUBLISH=true. Marketplace has no dependency on NuGet publication and no post-upload gallery availability poll.

Validation: version tests, Prettier, actionlint, final build, independent review, and publisher upload results. Prepublication build/tests and artifact identity remain required; registry indexing is not a publishing gate.
