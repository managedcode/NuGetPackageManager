# Acceptance contract

Actor: a developer in a file-backed local/remote VS Code .NET workspace. Entry: NuGet command palette command or project-file context menu. Read operations work in restricted mode; writes require workspace trust.

| ID     | Pass condition                                                                                      | Failure/edge condition                                                                                   | Proof                                                             |
| ------ | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| AC-001 | Discover literal central and project versions in a multi-root workspace                             | Comments/CDATA ignored; malformed XML and expressions reported                                           | Parser tests and VS Code host integration                         |
| AC-002 | Compare numeric NuGet versions, stable/prerelease and 4th component                                 | Properties, ranges and wildcards never become targets                                                    | Version tests                                                     |
| AC-003 | Check listed versions through actual NuGet V3 HTTP resources with bounded concurrency               | Missing package, failed source and cancellation remain distinguishable                                   | Local HTTP feed integration and live nuget.org smoke              |
| AC-004 | Filter by file/family/type, select updates and review exact file/version changes                    | No hidden selection applied; narrow view preserves explicit selection                                    | Browser interaction evidence and host integration                 |
| AC-005 | Apply only selected version text after exact snapshot validation                                    | Any changed document rejects whole plan; preserve BOM/CRLF/comments, unsaved edits and undo              | Parser tests and host integration                                 |
| AC-006 | Package an installable VSIX and ship through cross-platform GitHub CI                               | Compilation, test, formatting or packaging failure blocks release                                        | CI artifacts and local VSIX inspection                            |
| AC-007 | Keep UI usable in dark/light themes and narrow windows                                              | Dynamic content escaped; webview CSP disallows arbitrary scripts/network                                 | Browser visual evidence and independent review                    |
| AC-008 | VS Code and NuGet global tool use one .NET engine; public tool package installs and runs from NuGet | Missing runtime and publication credentials are actionable errors; CLI name needs explicit user approval | Shared bridge/CLI tests, packed tool install, actual feed install |
| AC-009 | Select and review an entire family or dotted subfamily together in both hosts                       | Case-insensitive exact/dot boundary matching; sibling prefixes excluded; all selected edits visible      | Family engine tests, actual host and browser review               |

No automatic solution restore or API compatibility guarantee. Applying central versions intentionally affects all their consumers. Authenticated feeds and source mapping are explicitly unsupported. VS Code host integration is primary behavioral proof; browser demo is supplementary visual evidence.
